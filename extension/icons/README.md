# Scout Icons

Create or copy these icon files here:
- `scout16.png` (16x16)
- `scout48.png` (48x48)
- `scout128.png` (128x128)

You can use any simple compass/navigator icon, or generate one with:
- https://favicon.io/favicon-generator/
- https://www.canva.com/
- Any 16x16/48x48/128x128 PNG set

The extension will load without icons (Chrome shows a default puzzle piece), but proper icons are recommended before publishing.
